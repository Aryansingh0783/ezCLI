What ezCLI found
    Selected session

    Gemini CLI setup: Personal Google sign-in is no longer supported here. Use Antigravity CLI for a personal account; Gemini CLI needs a Gemini API key, Vertex AI, or an enterprise setup.

    ezCLI only opens local CLIs. It does not send prompts to a model itself, and you can switch backends for any session.

    Knowledge graph

    Graphify (third-party, open source) turns each project into a graph your agents can query. ezCLI merges them into one second brain: a graph window, plus notes for Obsidian. It stays on this PC, in ~/.ezcli/second-brain. ezCLI shows you each command before it runs.

    Connectors
    
        
    Connect a remote MCP server you've already set up yourself — Strata, your own tool server, or anything else that speaks MCP over HTTP. These are third-party servers, not part of ezCLI, and ezCLI never creates an account or connects anything on its own: you set each one up and paste in its URL. Once added and enabled, a connector attaches automatically to every session that can receive it — no per-session toggle. Turn one off for one tab with the Connectors chip in that session's header, or disable/remove it here to turn it off everywhere.
