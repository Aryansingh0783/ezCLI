# Logo brief for the app

Paste this into Claude Design.

---

## What I need

A new logo and app icon for **ezCLI**, a desktop app that runs every coding command-line agent (Claude Code, Codex, Gemini CLI, OpenCode, Ollama and others) in one calm window. I need:

1. A **symbol / app icon** that works as a rounded square and stands alone with no text.
2. A **wordmark lockup** (symbol + name), horizontal.
3. A **monochrome version** (one colour, plus a white-on-dark version).
4. Variations of the symbol only, so I can choose a direction. Please give 4 to 6 distinct ideas, not 6 colour swaps of one idea.

## What the product is

- A desktop window (Windows, macOS, Linux) that starts the real CLI of each AI coding agent in a real terminal. It does not replace the agents; it gives them a good home.
- Around the terminal it adds: a sidebar of projects and sessions, a message box, a file and diff explorer, compare mode (one prompt, several agents side by side), team chat (agents taking turns), project instructions, and a "second brain" map of your code.
- Audience: developers who use more than one AI coding tool and want one tidy place for them.

## The idea the logo should carry

- **Many agents, one calm place.** Several things gathered into one.
- **Warm, human, unhurried.** The opposite of a neon hacker terminal.
- **Terminal underneath.** A nod to the command line (a prompt `>`, a cursor bar `_`, a block cursor) is welcome, but it must not look like a generic terminal icon.

Ideas to explore (do not limit yourself to these): a hearth or flame made of simple shapes; stacked or woven lines meeting in one point; a cursor block with a small spark; a ring or orbit holding several dots; tiles or tessellated squares; a kiln or doorway shape; a prompt chevron resolved into a warm shape.

## Look and feel

- **Style:** flat, geometric, confident, simple. Built from a few shapes with consistent corner radii. No gradients required, no glossy 3D, no drop shadows, no photo textures.
- **Feeling:** the same warmth as the Claude desktop app: cream paper, terracotta, charcoal, a serif for headings. Premium but approachable.
- **Avoid:** robots, brains, circuit boards, glowing neon, hexagons, chat bubbles, anything that looks like another AI company's mark, and the Claude / Anthropic spark itself (the app uses a small similar spark in its greeting, so the logo should look clearly different).

## Colour

Use these as the starting palette:

| Role | Hex |
|---|---|
| Terracotta (primary accent) | `#c24a22` (lighter `#d97757`) |
| Cream (light background) | `#faf9f5` / `#f5f4ed` |
| Charcoal (dark background and ink) | `#262624` / `#141413` |
| Warm grey (secondary text) | `#6a6963` |

The symbol must work in: terracotta on cream, cream on terracotta, and cream on charcoal. It must also work in pure black and pure white.

## Typography

- Wordmark: a modern humanist or geometric sans, lowercase or sentence case, medium weight. A refined serif is also welcome for a more editorial feel. Please show one of each.
- The in-app greeting uses a serif (Georgia style), so a wordmark that sits comfortably next to that is a plus.

## Where it will be used (design for the smallest first)

- **16 x 16 px**: the mark in the app's title bar and the window icon. It must stay readable here, so very few shapes.
- **24, 32, 48, 64 px**: taskbar, tray, installer, menus.
- **128, 256, 512 px**: app icon on Windows, macOS (rounded square, Big Sur style) and Linux.
- Website and GitHub README banner (wide, about 1280 x 440).
- Dark and light window chrome, and the macOS dock.

## Current logo (to replace)

Two vertical rounded bars side by side, a short one on the left and a taller one on the right, in terracotta. It reads like a small bar chart and says nothing about agents or terminals. Keep nothing from it unless you think it earns its place.

## Deliverables

- SVG for every version (symbol, lockup, mono, reversed).
- A PNG of the symbol at 16, 32, 64, 256 and 512 px so I can check small sizes.
- A short note on why each direction works and which one you would pick.

## The name: ezCLI

The name is final: **ezCLI**, pronounced "easy C-L-I". Casing is `ezCLI`: lowercase "ez", capital "CLI". Keep that casing in every lockup. It is a little playful and a little technical, which suits the idea: an easy place for command-line tools.

- Show the symbol without text first. It should work with no name beside it, and the app icon will be the symbol alone.
- For the wordmark, show how `ezCLI` looks set in one sans and one serif. Think about how the lowercase "ez" and the capitals "CLI" sit together: same weight, or a lighter "ez" and a stronger "CLI", or colouring "ez" in terracotta. Pick what looks best, and offer one alternative.
- The symbol may use the letters (an "e", "ez" or ">" shape) only if it stays clear at 16 px. A purely graphic mark is just as welcome.
- Nothing in the name or mark should suggest Claude, Anthropic, OpenAI or any other agent's brand. ezCLI works with all of them and belongs to none.
